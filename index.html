Why this stack?

  • Zero Hosting Bills: Combines GitHub Pages, Cloudflare Workers, and Turso free tiers.
  • Global Low Latency: Cloudflare edge nodes talk to Turso's globally distributed libSQL database.
  • No Secret Leaks: Turso auth tokens and database credentials remain secured inside Cloudflare Workers secrets, never exposed to client-side code.
  • Automated CI/CD: Included GitHub Actions workflows for continuous deployment of frontend and edge worker.
