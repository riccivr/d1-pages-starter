Why Cloudflare D1 + GitHub Pages?

  • No 3rd-Party Database Service: The database lives natively in Cloudflare right alongside your Worker. Zero token rotation or secret drift.
  • Instant Local Emulation: Run and test your SQLite database offline with wrangler dev and wrangler d1 execute --local without even creating a remote database!
  • Zero Cost: Leverages the generous free tiers of GitHub Pages and Cloudflare (5 million row reads/day, 100k writes/day, 5 GB storage).
  • Rock-Solid Security: Browser clients never touch the database. All queries execute through prepared statements inside the Worker.
